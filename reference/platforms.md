# Platforms & publishing

## Master spec
1080x1920, 30 fps, H.264 + AAC, ~-14 LUFS, **62–75 s** (never < 61 s: TikTok Creator Rewards only pays for videos over 1 minute). Same file for all four platforms.

## Monetisation notes (verify in each app's creator dashboard; rules change)
- **TikTok Creator Rewards:** videos > 1 min, original, 10k followers + 100k views/30 days, personal account. Duets/stitches/reuploads with minimal changes excluded.
- **Facebook content monetisation:** Philippines is eligible; mostly invite-based; original content required (plain reposts of TikToks may not qualify) — upload the clean master, never a TikTok-watermarked copy.
- **YouTube Shorts:** avoid repetitive/mass-produced patterns; original research and varied visuals every video.
- **Instagram Reels:** cross-post the clean master.

## Publish pack (`out/publish.md`)
- **YouTube Shorts:** title ≤ 60 chars (curiosity, not clickbait lies) + description (2 lines story tease, Sources line, credits) + 3 hashtags.
- **TikTok:** caption ≤ 150 chars with the hook question + 3–5 hashtags (#philippines #history #untoldstories + story-specific).
- **Facebook Reels:** caption with a question to spark shares in group chats + 2–3 hashtags.
- **Instagram Reels:** caption + 3–5 hashtags; first line = hook.
- **Pinned comment:** the specific ending question, plus "Sources in description".
- **Credits:** archive image credits (required for any CC BY image).
- Upload the clean `final.mp4` to every platform (no other platform's watermark).
